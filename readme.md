## 📋 О проекте

**Project Manager Bot** - это умный Telegram-бот для управления проектами. Он позволяет создавать, редактировать и отслеживать ваши проекты прямо в Telegram!

### ✨ Основные возможности

| Команда | Описание |
|---------|----------|
| `/new_project` | 📌 Создать новый проект |
| `/description` | 📝 Добавить описание проекту |
| `/add_photo` | 🖼 Добавить фото проекта |
| `/skills` | 🛠 Добавить навыки проекту |
| `/projects` | 📋 Просмотреть все проекты |
| `/delete` | 🗑 Удалить проект |
| `/update_projects` | ✏️ Изменить информацию о проекте |
| `/info` | ℹ️ Список всех команд |
